# 질문하기 (Query)

핵심: 위키에 있는 것은 [[링크]]로 인용하고, 없는 것은 "위키에 없음"이라고 밝힌 뒤 구분해서 보충한다. 분석 페이지를 저장했으면 반드시 `wiki-verify`.

1. `wiki/index.md`를 먼저 읽고 관련 페이지를 찾는다. 부족하면 `grep`으로 wiki/ 전체를 검색한다.
2. 관련 페이지를 읽고, 필요하면 원본 raw까지 확인한다.
3. 답변은 **위키 페이지 인용 [[링크]]와 함께** 한다. 위키에 없는 내용은 "위키에 없음"이라고 명시하고, 일반 지식으로 보충할 땐 구분해서 표시한다.
4. 형식은 질문에 맞게: 짧은 답, 비교표, 체크리스트, 타임라인 등.
5. 답이 **재사용 가치가 있으면**(비교·분석·새로운 연결 발견) `analysis` 페이지로 저장할지 제안한다. 사용자가 원하면 저장 → index·log 업데이트 → `wiki-verify`.
6. log.md에 query 기록 (저장하지 않은 간단한 질문은 기록 생략 가능).
