# 예시: 자료 1건을 넣으면 생기는 것

위키는 빈 상태로 시작합니다. 이 폴더는 자료를 한 건 넣었을 때 결과가 어떻게 생기는지 보여 주는 참고용입니다. 검사기와 hook은 `raw/`·`wiki/`만 보므로 이 폴더는 위키에 포함되지 않습니다. 필요 없으면 폴더째 지워도 됩니다.

| 파일 | 실제 위치였다면 | 내용 |
|---|---|---|
| `raw/2026-09-24_예시-메모-습관.md` | `raw/` | 사용자가 넣은 원본 메모 |
| `wiki/요약-메모-습관.md` | `wiki/` | `source` 페이지 — 자료 1건의 요약 |
| `wiki/하루-한-줄-메모.md` | `wiki/` | `concept` 페이지 — 요약에서 뽑은 개념 |

같은 작업으로 `wiki/index.md`에는 이런 줄이 추가됩니다.

```markdown
### 개인 메모
- [[요약-메모-습관]] — (예시) 메모 맨 위에 행동 한 줄을 붙이는 습관 (2026-09-24)

## 💡 개념 · 멘탈모델
- [[하루-한-줄-메모]] — 메모에 요약이 아니라 "무엇을 할지"를 먼저 쓴다 (2026-09-24)
```

`wiki/log.md` 맨 아래에는 이런 항목이 붙습니다.

```markdown
## [2026-09-24] ingest | (예시) 메모 습관에 대한 생각
- 대상 raw: `2026-09-24_예시-메모-습관.md`
- 생성: [[요약-메모-습관]], [[하루-한-줄-메모]]
- 수정: [[index]]
- 검증: 기계 검사 1회(오류 0 · 경고 0) · 의미 검토 1회차(마지막 회차 새 문제 0)
```
